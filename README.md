¿Qué hay en este repositorio?

Aquí encontraras el código fuente del servidor de la app móvil Amplia

¿Qué es amplia?

Amplia es una app móvil multiplataforma, un lugar donde las personas interesadas en rentar vehículos, viviendas o 
publicar en renta cualquiera de estos 2 tipos de productos podrán hacerlo,
dando a conocer sus productos o encontrar estos tipos de productos en venta.
